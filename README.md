# 🚀 2D Space Game

A thrilling 2D space game built in **Unity** where you pilot a rocket through the cosmos — navigating from launch platform to destination platform across progressively challenging levels.

---

## 🎮 About the Game

Take control of a rocket and carefully maneuver through space to land safely on the destination platform. Each level introduces new obstacles and layouts that test your precision and control. How far can you go?

---

## 🕹️ Gameplay

- **Objective:** Fly your rocket from the starting platform and land it on the destination platform to advance to the next level.
- **Controls:** Thrust and steer your rocket using keyboard inputs.
- **Challenge:** Avoid crashing into obstacles or flying off course — one wrong move and you restart the level!

### Default Controls

| Key | Action |
|-----|--------|
| `Space` / `W` / `↑` | Thrust (move forward) |
| `A` / `←` | Rotate Left |
| `D` / `→` | Rotate Right |

---

## 🌌 Features

- 🚀 Rocket flight mechanics with realistic thrust and rotation
- 🪐 Multiple levels with increasing difficulty
- 🛬 Platform-to-platform landing challenges
- 💥 Crash detection — hit an obstacle and retry the level
- 🎯 Satisfying landing system — reach the destination to progress
- 🌠 Space-themed 2D visuals

## 🚀 Getting Started

### Prerequisites

- Unity **2021.3 LTS** 

### Running the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/KumarAyush26/2D-Space-Game.git
   ```
2. Open **Unity Hub** and click **"Add project from disk"**
3. Navigate to the cloned folder and open it
4. Press the **Play** button in the Unity Editor to start playing
